第1章：人形机器人概述

本章导语：人形机器人（Humanoid Robot）——这个曾经只存在于科幻小说中的概念，如今正在成为现实。从早稻田大学的第一台双足步行机器人WABOT，到Tesla Optimus走进工厂流水线，人形机器人经历了近半个世纪的技术积累。本章将从定义出发，系统梳理人形机器人的发展历程、全球产业格局、核心技术体系与典型产品，并在最后通过MuJoCo仿真实操迈出你的第一步。无论你是机器人领域的初学者，还是希望建立系统性知识框架的进阶者，本章都将为你奠定坚实的基础。

1.1 什么是人形机器人​

1.1.1 定义与核心特征​

人形机器人（Humanoid Robot），顾名思义，是指外形和运动方式模仿人类的机器人系统。更准确地说，人形机器人是一类具有类人形态——包括头部、躯干、双臂和双腿——并且能够实现双足行走、双臂操作和头部感知的机器人平台。

在学术定义上，人形机器人需要满足三个核心特征：

（一）类人形态（Human-like Morphology）

人形机器人的外形设计以人体解剖结构为蓝本。典型的构型包括：

  • 头部：搭载视觉传感器（双目相机、深度相机）、麦克风阵列以及扬声器，用于感知环境和与人交互。部分高端机器人还集成了LED表情显示屏（如小米CyberOne、Engineered Arts Ameca），用于表达简单情绪。
  • 躯干：容纳主控计算单元（如NVIDIA Jetson AGX Orin或Intel Core i7/i9）、电池组、IMU（惯性测量单元，Inertial Measurement Unit）等核心部件。躯干的设计需要在空间紧凑性与散热性能之间取得平衡。
  • 双臂：每个手臂通常具有6-7个自由度（Degrees of Freedom，DoF），包括肩关节（3轴：俯仰/偏航/翻滚）、肘关节（1轴：俯仰）和腕关节（2-3轴：俯仰/偏航/翻滚）。这使得人形机器人能够完成从简单抓取到复杂装配的多样化操作。
  • 双手：灵巧手（Dexterous Hand）通常具有5-12个自由度，通过多指协调实现精细操作。当前的灵巧手大致分为欠驱动手（如Shadow Hand的简化版本）和全驱动手（如Inspire Hand）两类。
  • 双腿：每条腿通常具有5-6个自由度（髋关节3轴、膝关节1轴、踝关节2轴），通过驱动器的协调控制实现稳定的双足行走、奔跑、跳跃甚至爬楼梯。

（二）双足运动（Bipedal Locomotion）

双足运动是人形机器人区别于轮式机器人、四足机器人的最显著特征。双足运动带来的核心挑战包括：

  • 欠驱动系统：双足支撑时只有脚底与地面接触，属于"浮动基座"系统。在单脚支撑阶段（单脚离地），系统处于欠驱动状态（underactuated），即控制输入维度少于自由度总数。
  • 不稳定性：双足行走本质上是一个周期性失稳再恢复平衡的过程。每一步都需要精密的姿态控制来防止摔倒。
  • 能量效率：人类双足行走的能量效率极高（约0.2的Cost of Transport，CoT），而当前人形机器人的CoT约为人类的5-10倍，这是亟待改善的方向。

（三）灵巧操作（Dexterous Manipulation）

灵巧操作是指机器人通过多指协调、力控感知和视觉反馈，实现对物体的精细操作能力。这包括：

  • 力控抓取：不仅要抓取物体，还要控制施加的力度——抓鸡蛋不碎，抓工具不滑。
  • 在-hand操作（In-hand Manipulation）：如在手心转动一支笔、拼装乐高积木等精细动作。
  • 工具使用：使用螺丝刀、锤子、扳手等人类工具，这就要求机器人理解工具的功能并调整手部姿态。

这三个核心特征——类人形态、双足运动、灵巧操作——共同定义了人形机器人的范畴。缺少其中任何一项，通常就被归入其他类型的机器人。

1.1.2 与其他类型机器人的区别​

工业机械臂（Industrial Manipulator / Robotic Arm）是目前工业界最成熟的机器人形态。它们通常固定在工作台上或沿轨道移动，以极高的精度（重复定位精度可达±0.02mm）和速度执行焊接、喷涂、装配等任务。但工业机械臂缺乏移动能力，且通常需要安全围栏隔离。

轮式机器人（Wheeled Robot）以移动能力见长，典型代表包括自主移动机器人（AMR，Autonomous Mobile Robot）和扫地机器人。轮式机器人在平坦地面上效率极高，但无法跨越台阶、门槛或崎岖地形。它们通常配备一个简单的机械臂或托架，操作能力有限。

四足机器人（Quadruped Robot）以Boston Dynamics的Spot和宇树科技的B2为代表。四足机器人在崎岖地形中的运动能力远超轮式机器人，但缺乏人形机器人的双臂操作能力——四足机器人"没有手"，只能携带传感器进行巡检任务。

1.1.3 为什么选择人形形态​

既然工业机械臂更精准、轮式机器人更便宜、四足机器人更稳定，为什么还要发展人形机器人？这个问题的答案，正是人形机器人存在的最根本理由：

我们的世界是为人类形态设计的。

这句话的深刻含义体现在以下几个方面：

（一）环境适配性（Environment Compatibility）

人类建造的建筑、工具、设备和基础设施，全部以人体尺寸和能力为设计基准。例如：

  • 楼梯的宽度（约90cm）和高度（约17cm）适合人类步幅
  • 门把手的高度（约90-110cm）适合人类手臂操作
  • 汽车驾驶舱的座椅、踏板、方向盘布局基于人体工学
  • 工厂产线的操作高度、通道宽度以人类工人的作业范围为基准
  • 家庭环境中的厨房台面（约85cm）、开关高度、储物柜等均适配人类

一台人形机器人无需改造环境就可以直接进入这些场景作业，而其他形态的机器人要么无法进入（轮式不能上楼梯），要么需要昂贵的环境改造（安装导轨、坡道等）。

（二）工具通用性（Tool Universality）

人类发明了成千上万种手持工具——螺丝刀、扳手、剪刀、锤子、刀具、笔、手机……这些工具的设计全部基于人手的能力和尺寸。人形机器人的灵巧手可以直接使用这些工具，无需为机器人定制专用工具。这带来了巨大的成本优势：工厂不需要改造工具，家庭不需要购买新设备。

（三）社会接受度（Social Acceptance）

心理学研究表明，人类对与自己形态相似的实体具有更高的信任度和交互意愿（这种现象被称为"类人效应"或相似性偏好）。人形机器人的类人外观降低了人类的心理戒备，使得人机协作更加自然。在家庭陪伴、养老护理、教育等场景中，这一优势尤为明显。

当然，人形形态也并非没有缺点——双足运动的不稳定性、更高的成本、更复杂的控制算法都是现实挑战。但正是这些挑战，驱动着全球数千名研究人员和工程师不断突破技术边界。正如Boston Dynamics的创始人Marc Raibert所说："如果做简单的事情就能完成所有任务，我们就不需要人形机器人了。但现实世界需要我们能够处理各种复杂环境——这就是人形机器人的终极价值。"

1.2 人形机器人发展简史​

人形机器人的发展史可以概括为四个阶段：萌芽期（1970s-1990s）、探索期（2000s-2015）、爆发期（2016-2023）和产业期（2024-至今）。下面，我们沿着时间线逐一回顾。

1.2.1 萌芽期（1970s-1990s）：从零到一​

人形机器人的研究可以追溯到20世纪70年代，那时计算机科学和机器人学都处于起步阶段，但先驱者们已经开始了大胆的探索。

WABOT系列（早稻田大学，1973）

世界公认的第一台人形机器人是日本早稻田大学加藤一郎（Ichiro Kato）教授团队于1973年开发的WABOT-1。WABOT-1身高约2米，配备了两条腿、两只手臂和一套视觉系统。它能够测量距离和方向，通过触觉传感器抓取物体，并且实现了每分钟一步的缓慢双足步行——这在当时是划时代的成就。

但是，WABOT-1的步行方式属于"静态步行"（static walking），即在每一步中保持重心投影始终落在支撑脚面积内，交替移动双腿。这种步行方式虽然稳定，但速度极慢，且无法应对动态干扰。

1984年，加藤团队推出了WABOT-2，这是一台专门用于演奏电子琴的机器人。WABOT-2配备了五根手指的灵巧手，能够通过视觉读取乐谱并演奏中等难度的曲目。虽然功能局限，但WABOT-2展示了人形机器人在精细操作方面的潜力。

本田E系列/ASIMO前驱（1986-2000）

1986年，日本本田（Honda）公司秘密启动了人形机器人研究项目。与学术界的研究不同，本田从一开始就以实用化为目标，投入了巨大的研发资源。

本田团队先后开发了E0到E6七台实验平台（E代表"Experimental"），专注于双足行走的研究。其中E0（1986年）只能实现简单的静态行走，而E6（1993年）已经能够实现动态行走——即行走过程中重心不完全落在支撑脚内，利用身体惯性维持平衡。

1996年，本田推出了P1和P2（Prototype型号），这是最早的自立型（自备电池和控制器）人形机器人。P2高182cm，重210kg，虽然体积庞大，但已经具备了在人类环境中行走的基本能力。

2000年，本田发布了震惊世界的ASIMO（Advanced Step in Innovative Mobility）。ASIMO高120cm，重52kg，能够以1.6km/h的速度行走，上下楼梯，甚至向人挥手致意。ASIMO在随后的20年中成为人形机器人领域最具代表性的符号之一。

1.2.2 探索期（2000s-2015）：百家争鸣​

进入21世纪，人形机器人研究开始在全球范围内展开，形成了多个研究阵营和技术路线。

Honda ASIMO的持续进化（2000-2011）

ASIMO在2000年首次亮相后，本田对其进行了多次重大升级：

  • 2002年：ASIMO增加了跑步功能，速度提升至2.5km/h
  • 2005年：升级版ASIMO实现了倒走、单脚跳和双手操作
  • 2007年：ASIMO可以自主避障，识别移动物体和人的手势
  • 2011年：最后一个大版本——ASIMO学会了单脚跳、使用手指拧开水瓶，速度达到9km/h

ASIMO虽然在技术演示上令人印象深刻，但其造价极其高昂（据估计每台超过200万美元），且实际应用场景有限。这预示了人形机器人商业化面临的根本困境。

HRP系列（日本产综研/AIST，1998-至今）

日本产业技术综合研究所（AIST，National Institute of Advanced Industrial Science and Technology）与川田工业合作，从1998年开始开发HRP（Humanoid Robotics Project）系列。HRP系列的目标是建立人形机器人的标准化平台，供学术界和产业界使用。

  • HRP-2（2002年）：身高154cm，重58kg，具有30个自由度。HRP-2是当时最先进的人形机器人研究平台之一
  • HRP-3（2006年）：增强了防尘防水能力，面向实际工业应用
  • HRP-4（2010年）：更轻量化（39kg），外形更加拟人
  • HRP-5P（2018年）：专为建筑工地设计，能够自主完成石膏板安装等重体力劳动

HRP系列为全球人形机器人研究提供了开放平台，推动了运动控制、感知和规划算法的快速发展。

KHR系列（韩国KIST，2004-2010）

韩国科学技术研究院（KIST）在2004年推出了KHR-1（KAIST Humanoid Robot 1），随后开发了KHR-2（2005年）和HUBO（2006年）。HUBO身高125cm，重55kg，能够以1.2km/h的速度行走，并拥有可抓取物体的双手。

2015年，KIST与Drexel University合作开发的**HUBO 2+**在DARPA机器人挑战赛（DRC，DARPA Robotics Challenge）中获得第一名，完成了开车、开门、拧阀门等八项任务。

Boston Dynamics Atlas（液压时代，2013）

2013年，Boston Dynamics（当时隶属于Google的Alphabet）发布了Atlas的第一代版本。Atlas最初是为美国国防高级研究计划局（DARPA，Defense Advanced Research Projects Agency）开发的，用于参与DRC挑战赛。

第一代Atlas高188cm，重150kg，采用液压驱动系统（hydraulic actuation）。液压系统赋予了Atlas惊人的力量密度和动态性能——它可以举起45kg的重物，可以承受撞击后恢复平衡。但液压系统也有明显缺点：噪音大、效率低、油液泄漏风险高。

尽管如此，Atlas的出现标志着人形机器人在动态运动能力上的一次质变。它不再像之前的机器人那样"慢吞吞"，而是展现出了接近人类运动员的身体素质。

1.2.3 爆发期（2016-2023）：从实验室走向市场​

2016年前后，三大趋势推动了人形机器人领域的爆发式发展：深度学习的成熟、电驱技术的进步以及大模型的出现。

Atlas后空翻（2017）

2017年11月，Boston Dynamics发布了一段视频，Atlas完成了完美的后空翻（Backflip）。这段视频在社交媒体上获得了数千万次观看，让Atlas一夜之间成为全球最知名的机器人。

虽然这本质上是一个精心编排的演示动作，但它证明了人形机器人可以达到的运动极限远超人们的想象。Atlas随后还展示了跑酷（2018年）、体操（2019年）和跳舞（2020年）等技能，每一次发布都引爆了公众关注。

电驱转型：从液压到电驱动

长期以来，人形机器人领域存在"液压 vs 电驱"的技术路线之争。液压驱动（如Atlas早期版本）力量大、动态性能好，但成本高、维护复杂。电驱动（如ASIMO、HRP）控制精度高、成本低，但力矩密度相对不足。

2018年之后，随着无框力矩电机（如科尔摩根TBM系列、TQ Robodrive系列）和高性能谐波减速器（如哈默纳科、绿的谐波）的成熟，电驱动方案的力矩密度大幅提升，逐渐具备了替代液压方案的能力。这场"电驱革命"为人形机器人的商业化铺平了道路。

Tesla Optimus发布（2021-2022）

2021年8月的Tesla AI Day上，Elon Musk首次公布了Tesla Bot（后更名为Optimus） 的概念。2022年9月，Tesla AI Day上展示了Optimus的原型——一个可以行走、挥手、搬运箱子的机器人。

Optimus的发布是人形机器人产业化的一个关键转折点。不同于此前的机器人公司（如Boston Dynamics）专注于技术演示，Tesla从一开始就强调可量产性（manufacturability） 和低成本。Musk提出了Optimus的最终目标价——$20,000/台，这远低于当时任何同类产品。

Tesla的优势在于：成熟的电驱动技术（从Tesla汽车迁移）、强大的供应链整合能力、以及FSD（Full Self-Driving）自动驾驶系统在感知与决策方面的技术积累。

小米CyberOne（2022）

2022年8月，小米在秋季新品发布会上推出了CyberOne（铁大）。CyberOne高177cm，重52kg，搭载了小米自研的伺服电机和Mi-Sense深度视觉模块。

CyberOne的定位是"家庭服务机器人"，但小米明确表示它尚未商业化，更多是技术储备和品牌展示。小米的入场进一步表明：人形机器人正在成为科技巨头的必争之地。

具身智能浪潮（2023）

2023年，随着ChatGPT（2022年底发布）引爆的大语言模型浪潮，"具身智能（Embodied Intelligence，EI）"概念开始与人形机器人深度结合。学术界和工业界意识到：大语言模型（LLM，Large Language Model）和视觉-语言模型（VLM，Vision-Language Model）可以为人形机器人提供"大脑"，使其具备理解指令、规划任务和自主决策的能力。

代表性进展包括：

  • Google DeepMind的RT-2（2023年7月）：首个视觉-语言-动作模型（VLA，Vision-Language-Action Model），直接从视觉和文本输入输出机器人动作
  • PaLM-E（2023年3月）：将PaLM大语言模型与机器人感知相结合
  • Figure AI成立（2022年）：专门开发具身智能人形机器人的创业公司，2023年获得OpenAI投资

2024年被很多人形机器人从业者称为"人形机器人产业化元年"。这一年，多个公司的产品从原型走向了小批量生产和实际部署。

Figure 02（2024年8月）

Figure AI在2024年发布了Figure 02，这是一台专门为具身智能设计的人形机器人。Figure 02的核心亮点包括：

1X NEO（2024）

挪威的1X Technologies（由OpenAI投资的机器人公司）在2024年发布了NEO——一款面向家庭场景的人形机器人。NEO的设计理念是"安全至上"：轻量化（约30kg）、柔性外壳、力矩限制，确保在家庭环境中不会对人造成伤害。

NEO代表了与工业机器人完全不同的设计路线：它不以力量和速度取胜，而是以安全性和亲和力为核心竞争力。

宇树科技 H1 / G1（2024）

中国公司宇树科技（Unitree，以四足机器人Go1起家）在2024年连续发布了H1和G1两款人形机器人。

  • G1：2024年5月发布的小型版，高127cm，重35kg。G1的起售价仅$16,000（约¥99,000），是目前"最便宜"的人形机器人之一

宇树以"高性价比"策略迅速切入市场，H1和G1在科研和教育领域获得了大量订单。

智元机器人 远征A2（2024）

智元机器人（Agibot，由前华为"天才少年"彭志辉创立）在2024年发布了远征A2（Expedition A2）。A2定位为"工业级通用双足机器人"，专为工厂自动化场景设计。

A2的关键参数：身高170cm，高性能关节模组自研，搭载了公司自研的POWER关节。智元明确瞄准ToB市场，与多个制造企业合作推进实际部署。

星动纪元 STAR 1（2024）

1.3 全球产业格局​

截至2025年，人形机器人产业已经形成了清晰的全球竞争格局。我们可以从北美、中国、日韩及欧洲三个阵营来理解当前的产业版图。

1.3.1 北美阵营​

Tesla（Optimus）

Tesla是人形机器人产业化的"旗手"。Elon Musk将Optimus视为Tesla长期价值的核心——他甚至在一次投资者日上表示："长期来看，Optimus的业务价值将超过Tesla汽车业务。"

Optimus的设计哲学源自Tesla的"第一性原理"（First Principles Thinking）：

  • 电驱：从Tesla汽车的电驱系统迁移，复用成熟的电池、电机和热管理技术
  • FSD技术迁移：Optimus的视觉感知系统基于Tesla纯视觉自动驾驶方案，复用Occupancy Networks和NeRF（Neural Radiance Fields）等感知技术
  • 规模化：Optimus从设计之初就考虑了大规模量产——减少零件数量、采用注塑工艺、使用成熟供应链

Optimus Gen 2（2023年12月发布）相比Gen 1有了显著进步：步行速度提升30%，减重10kg，增加了脚部力传感器和灵巧手的触觉传感。

截至2025年中，Tesla表示已在自有工厂部署了数台Optimus进行电池模组分拣、物料搬运等任务，并计划2026年实现对外销售。

Boston Dynamics（Atlas电驱化）

Boston Dynamics是人形机器人动态运动能力的王者。从2013年的液压版Atlas开始，BD团队在双足运动控制方面积累了无可争议的技术优势——后空翻、跑酷、体操舞，每一项都刷新了行业对运动能力的认知。

2024年4月，Boston Dynamics发布了全电驱版Atlas（All-Electric Atlas），正式告别了液压驱动。电动Atlas保留了上一代的运动能力，同时大幅降低了噪音和维护成本。与BD以前的"技术演示"风格不同，电驱Atlas明确瞄准了工业应用场景。

2025年，Boston Dynamics被现代汽车集团（Hyundai Motor Group）以全资收购，这为BD提供了汽车制造商在规模化生产方面的经验。

Figure AI（Figure 02）

Figure AI成立于2022年，总部位于美国加州，由Brett Adcock（此前创立了Vettery和Archer Aviation）创立。Figure的愿景明确：开发"世界上第一个商业化量产的人形机器人"。

Figure与OpenAI的深度合作是公司最受关注的特点。Figure 01在2024年初的一次演示中展示了令人惊叹的能力：它与人类进行自然语言对话，根据人类指令"给我一些吃的"自主识别桌上的苹果、递过去、整理桌面——整个过程完全由AI驱动，没有预设的脚本。

Figure 02（2024年8月发布）进一步强化了AI原生设计：6个RGB摄像头提供360°感知、自研灵巧手、计算单元采用定制的AI芯片。Figure已在BMW的斯帕坦堡工厂进行试运行，完成车身零部件的搬运和装配任务。

融资方面，Figure在2024年完成了6.75亿美元的B轮融资，估值达26亿美元，投资方包括Microsoft、OpenAI、NVIDIA、Jeff Bezos等。

1.3.2 中国阵营​

中国在人形机器人领域的崛起速度令全球瞩目。依托完整的制造业供应链、庞大的人才储备和积极的政策支持（如北京、上海、深圳等地的人形机器人产业扶持计划），中国已成为人形机器人产品化最活跃的地区。

宇树科技（Unitree，H1 / G1）

宇树科技成立于2016年，以四足机器人Go1、B2闻名。2023年进入人形机器人领域，凭借在四足机器人上积累的运动控制技术迅速推出H1和G1。

宇树的差异化竞争优势在于性价比。G1的起售价$16,000远低于同类产品，H1在9万美元价位提供了后空翻级别的运动能力。这种"降维打击"策略使宇树在科研、教育市场迅速占据份额。

宇树的技术特色包括：自研高力矩密度电机、基于NVIDIA Isaac Gym的强化学习训练框架、Sim2Real迁移能力。值得注意的是，H1是全球首台展示原地后空翻的纯电驱人形机器人。

智元机器人（Agibot，远征A2）

智元机器人由前华为"天才少年"彭志辉（人称"稚晖君"）于2023年2月创立，成立仅一年后估值即超10亿美元。智元聚焦"工业级通用机器人"，不追求消费市场。

远征A2的关键特色是自研的POWER关节模组——集成无框力矩电机、谐波减速器、力矩传感器、编码器和驱动电路的一体化关节。这种垂直整合策略降低了成本并提高了可靠性。

智元已与多家制造业企业（包括比亚迪等）达成合作协议，推进人形机器人在汽车产线的部署。

傅利叶智能（Fourier，GR-2）

傅利叶智能成立于2015年，原本专注于康复机器人（外骨骼和康复训练设备）。2023年推出人形机器人GR-1，2024年升级为GR-2。

傅利叶的独特优势来自康复技术的迁移：

  • 力控技术：康复机器人天然需要力控，GR-2在关节力矩控制方面具有深厚积累
  • 安全性：康复设备对安全性要求极高，GR-2的力限制与碰撞检测技术领先
  • 临床应用理解：傅利叶的产品在医疗康复场景中具有天然优势

GR-2的灵巧手采用全驱动方案（每指独立电机），配备了指尖触觉传感器，可完成鸡蛋抓取、针线穿行等精细操作。

星动纪元（Star Dynamics，STAR 1）

星动纪元成立于2023年，核心团队来自清华大学。STAR 1的技术特色是端到端模仿学习——通过大量人类遥操作数据直接训练从视觉到动作的端到端策略，而不是传统的手工设计运动控制器。

STAR 1在2024年展示了搬运箱子、开门、跨门槛等操作能力。2024年完成Pre-A轮融资约3亿元人民币。

小米（CyberOne / CyberDog系列）

小米的CyberOne（2022年发布）更多是技术储备和生态布局，尚未进入真正意义上的产品化阶段。但小米的优势在于：消费级品牌认知、强大的供应链管理能力、以及AIoT（人工智能物联网，Artificial Intelligence Internet of Things）生态系统。

小米的CyberDog系列（四足机器人）在全球有数十万台销量，为人形机器人的规模化提供了经验和基础。

1.4 人形机器人的核心技术体系​

人形机器人是一项高度跨学科的系统工程。一台能够自主行走、操作和交互的人形机器人，需要硬件、软件和智能系统三大部分的紧密配合。本节将从系统架构的视角，梳理人形机器人的核心技术体系。

1.4.1 硬件系统架构​

（一）关节与驱动系统

关节是人形机器人的"肌肉"。每一个关节需要具备高力矩密度、高响应速度和高精度的特性。

一套典型的关节模组包含以下组件：

┌─────────────────────────────────────┐
│           关节模组                      │
│  ┌──────────┐  ┌──────────────┐      │
│  │无框力矩电机│→│ 减速器         │      │
│  │(电机转子) │  │(谐波/行星)    │      │
│  └──────────┘  └──────┬───────┘      │
│                       ↓              │
│  ┌──────────┐  ┌──────────────┐      │
│  │编码器(位置)│  │力矩传感器(力控)│      │
│  └──────────┘  └──────────────┘      │
│                       ↓              │
│  ┌──────────┐  ┌──────────────┐      │
│  │电机驱动器 │←─│ 主控通信总线   │      │
│  └──────────┘  └──────────────┘      │
└─────────────────────────────────────┘

关键元件说明：

  • 无框力矩电机（Frameless Torque Motor）：通过将电机转子直接集成到关节轴上，实现了高力矩密度和紧凑体积。主流供应商包括科尔摩根（Kollmorgen，TBM系列）、TQ Robodrive和国产的步科、汇川技术等
  • 减速器（Reducer）：将电机的高速低扭矩输出转换为低速高扭矩输出。常用的有谐波减速器（Harmonic Drive，精度高、体积小、但成本高）和行星减速器（成本低、但间隙大）。谐波减速器的全球领导者是日本哈默纳科（Harmonic Drive Systems），中国的绿的谐波（Leaderdrive）正在快速追赶
  • 力矩传感器（Torque Sensor）：用于测量关节输出力矩，实现力控。六维力矩传感器（6-DoF Force/Torque Sensor）可以同时测量三个方向的力和三个方向的力矩，是实现精细操作的关键。中国公司坤维科技、宇立仪器等在这一领域有突出表现
  • 编码器（Encoder）：用于测量电机转子的位置和速度，通常采用绝对式磁编码器或光学编码器，分辨率可达19-24bit

（二）灵巧手

灵巧手是实现精细操作的核心部件，也是当前人形机器人最大的技术瓶颈之一。当前的灵巧手方案大致分为三类：

方案控制方式自由度特点代表产品
欠驱动手单电机驱动多手指5-6 DoF结构简单、成本低、控制容易Robotiq 2F-85
全驱动手每指独立电机6-12 DoF灵活度高、可做精细操作Inspire Hand, Schunk SVH
触觉手全驱动+触觉阵列6-12 DoF + 触觉可感知接触力分布Shadow Hand, 傅利叶触觉手

灵巧手面临的挑战包括：

  1. 空间限制：人手大小空间内需要集成多个电机、减速器和传感器
  2. 力控精度：精细操作需要精确控制指尖力量（如抓取鸡蛋需要约5-10N的力）
  3. 触觉感知：缺乏类似人类的触觉反馈，使机器人在执行精细化操作时"手笨"

（三）感知传感器

人形机器人的感知系统是它的"五官"：

  • 视觉传感器：双目RGB相机（如Intel RealSense D435i）用于立体视觉和深度估计；鱼眼相机用于大视角感知；事件相机（Event Camera）用于高速运动捕捉
  • 惯性测量单元（IMU）：集成加速度计（测量线性加速度）和陀螺仪（测量角速度），是姿态估计的核心传感器
  • 力/力矩传感器：脚底四维/六维力传感器用于测量地面反作用力，是实现行走控制的关键；腕部六维力传感器用于操作力控
  • 激光雷达（LiDAR，Light Detection and Ranging）：用于环境建图和障碍物检测
  • 麦克风阵列：用于语音定位和语音识别

（四）计算平台

人形机器人的"大脑"需要同时运行视觉感知、运动控制、AI推理等任务。当前主流计算平台包括：

  • NVIDIA Jetson AGX Orin / Orin NX：专为机器人设计的边缘AI计算平台，具有高达275 TOPS的AI算力
  • Intel Core i7/i9 + GPU：通用计算方案，适合原型开发
  • 定制AI芯片：部分公司（如Tesla、Figure）正在开发自己的AI推理芯片，以提高能效比

1.4.2 软件与智能系统​

如果说硬件是骨架，那么软件和智能系统就是人形机器人的"灵魂"。

（一）感知（Perception）

感知模块负责理解环境，主要包括：

  • 场景理解：通过深度学习模型（如YOLO、DETR）检测和识别环境中的物体、人和障碍物；通过语义分割理解场景的结构（地面、墙面、楼梯等）
  • 姿态估计：估计机器人自身各关节的位置和方向；估计环境中物体的6D位姿（位置+方向），以支持抓取操作
  • SLAM（Simultaneous Localization and Mapping，同时定位与地图构建）：在未知环境中同时构建地图和定位自身，是机器人自主移动的基础

（二）决策（Decision）

决策模块是机器人的"大脑"，负责从高层任务规划到底层动作生成：

  • 任务规划：将自然语言指令（如"去厨房倒一杯水"）分解为一系列子任务（"前往厨房→识别水杯→抓取→倒水→返回"）。大语言模型（LLM）在这一层面发挥了重要作用
  • 运动规划：规划从当前位置到目标位置的运动路径，需要考虑障碍物、地形条件和机器人自身运动能力
  • 动作生成：生成具体的关节运动轨迹或控制策略

（三）控制（Control）

控制模块是机器人的"小脑"，负责执行动作并保持平衡：

  • 模型预测控制（MPC，Model Predictive Control）：基于机器人的动力学模型，在预测时域内优化控制输入。MPC具有可解释性强、稳定性有理论保证的优点，但计算量大、对模型精度敏感
  • 全身控制（Whole-Body Control，WBC）：协调全身40-60个自由度，同时满足运动任务和平衡约束
  • 强化学习（RL，Reinforcement Learning）：通过仿真环境中的试错学习来训练运动策略。近年来，基于PPO（Proximal Policy Optimization）算法的RL训练在行走、跑步、跳跃等任务中取得了显著成效
  • Sim2Real迁移：将仿真中训练的策略迁移到真实机器人上，域随机化（Domain Randomization）是解决"仿真-现实差距"的核心技术

1.6 应用场景概览​

人形机器人的应用场景可以按照从"环境可控"到"环境全开放"、从"任务固定"到"任务通用"两个维度来分类。下面逐一简述五大核心场景。

1.6.1 工业制造​

工业制造是人形机器人目前最明确、最优先落地的场景。核心驱动因素在于：

  • 劳动力短缺：全球制造业面临严重的劳动力不足，特别是在重体力、高重复性的岗位
  • 柔性生产需求：频繁换线、小批量多品种的生产模式需要机器人具有灵活的适应能力
  • 环境适配：现有产线是按人类工人设计的，人形机器人可以直接适配而无需改造

典型应用包括：

  • 物料搬运：在仓库和产线间搬运重型零部件（单次负重5-15kg）
  • 装配操作：精密部件的安装、拧紧、焊接等
  • 质检巡查：利用多模态感知进行产品缺陷检测
  • 工具操作：使用人类工具（扳手、螺丝刀、电钻）进行维护和修理

Tesla、Figure AI、智元机器人均明确将工业制造作为首要目标市场。Tesla已在其工厂内部署Optimus进行电池模组分拣（2024），Figure 02在BMW工厂进行试点（2024），智元与比亚迪等车企合作探索产线部署。

1.6.2 物流仓储​

物流仓储场景与工业制造高度重叠，但有其独特性：

  • 动态环境：仓库布局频繁变化，箱子和货物的位置不是固定的
  • 多品类操作：需要处理各种尺寸、形状、重量的包裹和物件
  • 空间受限：货架间通道狭窄，需要机器人灵活转身和跨台阶

人形机器人相比传统的自主移动机器人（AMR，Autonomous Mobile Robot）的优势在于：可以直接从货架上取放物品（不需要传送带或升降机构），可以上下楼梯，可以操作各种尺寸的包裹。

代表应用：DHL和1X Technologies正在探索仓库场景的人形机器人部署。

1.6.3 家庭服务​

家庭服务是人形机器人的"终极梦想"市场，也是技术门槛最高的场景。核心原因在于：

  • 环境极度非结构化：每个家庭布局不同、物品摆放杂乱
  • 任务极度多样化：从扫地、洗碗、到照顾宠物、陪孩子玩耍
  • 安全性要求极高：家中可能有老人、小孩、宠物，任何碰撞都可能造成伤害
  • 成本敏感：消费者的价格接受度远低于工业客户

1X Technologies的NEO是最明确针对家庭场景的产品——轻量化（30kg）、柔性外壳、力矩限制、静音运行，所有设计都围绕"安全"和"亲和力"展开。

家庭服务的人形机器人普及预计要到2030年之后，核心制约因素包括成本（目标$10K-20K）、技术成熟度和安全标准。

1.6.4 医疗护理​

医疗护理是人形机器人可以产生巨大社会价值的场景：

  • 康复训练：协助患者进行物理治疗，GR-2等机器人的力控能力在此场景中具有独特优势
  • 手术辅助：高精度操作辅助，目前更多由专用手术机器人（如达芬奇系统）完成
  • 病房服务：送药、消毒、巡检、陪护
  • 养老护理：协助老人起床、行走、如厕，提供陪伴和照护

傅利叶智能在医疗护理场景中具有天然优势——其康复机器人产品和临床经验可以直接迁移到人形机器人平台。

1.6.5 特种作业​

特种作业包括人类不适合或无法安全执行的任务：

  • 危险环境作业：核电站巡检与维护、化工厂泄漏处置、矿下作业等
  • 消防救援：进入火场进行搜救和物资运输
  • 太空探索：NASA的Valkyrie和SpaceX对人形机器人在火星基地建设中的潜力表示关注
  • 军事应用：后勤保障、排爆、区域巡逻（但这一应用面临较大的伦理争议）

特种作业场景对人形机器人的鲁棒性、耐久性和环境适应性提出了最高要求，是当前技术条件下最具挑战性的应用方向。

🛠️ 仿真实操：MuJoCo第一课​

实操代码路径：code/ch01-load-model/load_humanoid.py（位于项目根目录的 code/ch01-load-model/ 文件夹下）

实验目标​

本实操是人形机器人学习之旅的"Hello World"。通过本实验，你将：

  1. 加载一个真实的人形机器人MuJoCo模型，观察它的物理结构和关节配置
  2. 打印机器人的自由度信息，了解每个关节的名称、类型和运动范围
  3. 运行被动仿真，观察机器人在重力作用下的自然运动（以及为什么机器人需要控制算法才能站立）
  4. 建立对MuJoCo（Multi-Joint dynamics with Contact）仿真引擎的直观认识——这是后续所有仿真实操的基础

前置依赖​

在运行本实验之前，请确保你已经安装了必要的Python依赖。在终端中执行：

cd code/ch01-load-model
pip install -r requirements.txt

requirements.txt文件内容为：

mujoco>=3.0
numpy>=1.24
matplotlib>=3.7

如果你尚未安装MuJoCo，上述命令会自动安装。MuJoCo是一个开源的高性能物理仿真引擎，由Roboti LLC开发，现由Google DeepMind维护并免费提供使用。

实验步骤​

步骤1：加载模型并创建仿真

代码首先从 assets/models/ 目录加载一个预训练的人形机器人XML模型文件（MJCF格式，MuJoCo的标准模型描述格式）。MJCF文件定义了机器人的所有物理属性：连杆的质量和惯性、关节的类型和运动范围、碰撞体的形状和摩擦系数等。

# 核心代码（简化示意）
import mujoco
import mujoco.viewer

# 加载模型
model = mujoco.MjModel.from_xml_path("../../assets/models/humanoid.xml")
data = mujoco.MjData(model)

# 运行被动仿真
for i in range(1000):
    mujoco.mj_step(model, data)

步骤2：观察关节结构

加载模型后，代码会遍历机器人所有关节（joints），打印出每个关节的名称、类型（hinge/ball/slide等）和自由度索引。人形机器人通常包含：

  • 髋关节：左右各3个自由度（俯仰、偏航、翻滚）
  • 膝关节：左右各1个自由度（俯仰）
  • 踝关节：左右各2个自由度（俯仰、翻滚）
  • 肩关节：左右各3个自由度（俯仰、偏航、翻滚）
  • 肘关节：左右各1-2个自由度（俯仰，有些还有偏航）
  • 腕关节：左右各2个自由度（俯仰、偏航）
  • 颈部关节：2-3个自由度（俯仰、偏航）

总计通常超过30个自由度。

步骤3：打印自由度信息

代码将输出每个自由度的：

  • 名称（如"left_hip_pitch"）
  • 关节类型（hinge表示旋转关节）
  • 运动范围（弧度或角度）
  • 默认初始位置
  • 是否有限位

步骤4：运行被动仿真

最后，代码启动一个被动仿真：不给任何关节施加控制信号，让机器人在重力作用下自由运动。你会看到：

  • 机器人站立片刻后失去平衡
  • 双腿弯曲、身体前倾/后仰
  • 最终摔倒在地上

这个实验传达了一个重要信息：双足站立本质上是不稳定的。如果不施加主动控制（通过MPC、RL或其他控制算法），人形机器人在重力作用下会像任何非稳定系统一样倾倒。这正是人形机器人运动控制的根本挑战所在。

延伸思考​

  1. 自由度与稳定性：观察到的被动倒塌说明了什么？如果增加或减少腿部自由度，会如何影响行走的难度？

  2. 仿真与现实：MuJoCo是一个物理仿真引擎，它能够模拟重力、碰撞、摩擦力等物理现象。但仿真终究是真实物理的近似——想想有哪些物理现象是MuJoCo可能没有精确建模的？（提示：气动阻力、关节柔性、电机延迟……）

  3. 控制算法的重要性：在后续章节中，你将学习如何通过控制算法让机器人保持站立和行走。你认为"经典控制方法"（基于模型）和"学习方法"（基于RL）各有什么优劣？

  4. Sim2Real：在仿真中训练的策略能否直接迁移到真实机器人上？需要克服哪些差距？这个问题的答案将是第4章的核心内容。

本章小结​

本章从五个维度系统介绍了人形机器人的全貌：

  1. 概念与特征：人形机器人是具备类人形态、双足运动和灵巧操作能力的机器人系统。它的核心价值在于能够适配人类环境——这是其他机器人形态无法替代的。

  2. 发展历程：从1973年WABOT-1的"蹒跚学步"，到Atlas的"后空翻"，再到2024年多家公司进入产品化阶段——人形机器人在50年间经历了从实验室演示到产业化的跨越。

  3. 产业格局：北美（Tesla、Figure、Boston Dynamics）、中国（宇树、智元、傅利叶、星动纪元、小米）和日韩/欧洲（1X、PAL Robotics）三大阵营各具特色。中国在性价比和产品化速度上表现突出。

  4. 核心技术：人形机器人是硬件（关节、手、传感器、计算）、软件（ROS、控制、状态估计）和智能（大模型、RL、Sim2Real）的高度集成体。

  5. 典型产品：Optimus的规模化潜力、Figure的AI原生能力、宇树的高动态性能、GR-2的力控优势——不同产品各具特色，但共同指向一个方向：人形机器人正在从"能不能动"走向"能不能用"。
