第8章：双足行走与平衡

本章导语：双足行走是人形机器人最具标志性的能力，也是最具挑战性的控制问题。本章从ZMP稳定性理论出发，逐步深入到步态规划、平衡恢复和基于强化学习的行走控制。仿真实操中将使用PPO算法训练一个抗扰动站立策略。

8.1 双足行走的挑战​

双足行走在人类看来是自然而然的，但对机器人来说却是一项极其困难的任务。主要挑战包括：

  1. 不稳定性：人形机器人在行走过程中大部分时间处于单腿支撑状态，本质上是一个倒立摆——极不稳定
  2. 非线性：行走涉及大范围的关节运动，动力学高度非线性
  3. 混合动力学：行走是"支撑相"（脚着地）和"摆动相"（脚离地）的交替，系统的动力学方程在两者之间切换
  4. 环境不确定性：地面不平、未知的摩擦系数、外部扰动
  5. 物理约束：关节角度/速度/力矩极限、足底不能滑动

8.2 ZMP稳定性理论​

8.2.1 ZMP的定义​

零力矩点（Zero Moment Point, ZMP）是双足机器人稳定性最广泛使用的判据。

ZMP定义为地面上的一点，所有惯性力和重力的合力矩在该点处为零。当ZMP位于支撑多边形内部时，机器人可以稳定行走。

8.2.2 ZMP的计算​

对于简化模型，ZMP的位置可以通过以下公式计算：

$$ p_x = \frac{\sum_i m_i (\ddot{z}_i + g) x_i - \sum_i m_i \ddot{x}_i z_i}{\sum_i m_i (\ddot{z}_i + g)} $$

其中 $m_i$ 是第 $i$ 个刚体的质量，$(x_i, z_i)$ 是其质心位置。

ZMP稳定性准则：

  • 如果ZMP在支撑多边形内 → 机器人稳定
  • 如果ZMP靠近支撑多边形边缘 → 机器人接近不稳定
  • 如果ZMP在支撑多边形外 → 机器人会摔倒

8.2.3 线性倒立摆模型（LIPM）​

为了简化双足行走的分析和规划，最常用的简化模型是线性倒立摆模型（Linear Inverted Pendulum Model, LIPM）。它将机器人的所有质量集中到质心（CoM），并将腿视为一个可伸缩的连杆。

LIPM的动力学方程：

$$ \ddot{x} = \frac{g}{z_c} (x - p_x) $$

其中 $x$ 是质心水平位置，$z_c$ 是质心高度（假设恒定），$p_x$ 是ZMP位置。

LIPM的关键简化：质心高度恒定 + 质量集中在一点。这两个简化使得动力学方程成为线性的，从而可以解析求解。

8.3 步态规划​

8.3.1 步态参数​

一个完整的行走周期（Gait Cycle）由两个阶段组成：

阶段占比描述
支撑相（Stance Phase）约60%脚与地面接触
摆动相（Swing Phase）约40%脚在空中移动

步态规划需要确定以下参数：

  • 步长（Step Length）
  • 步频（Step Frequency）
  • 步宽（Step Width）
  • 质心轨迹（CoM Trajectory）
  • 足端轨迹（Foot Trajectory）

8.3.2 质心轨迹规划​

基于LIPM，可以通过预览控制（Preview Control）或模型预测控制（MPC）来生成连续的质心轨迹。核心思想是：给定未来的落足点序列，计算出稳定的质心轨迹。

8.3.3 足端轨迹规划​

摆动腿的足端轨迹通常使用五次样条（Quintic Spline）插值，确保起点和终点的位置、速度和加速度连续。

8.4 平衡恢复​

8.4.1 Capture Point理论​

Capture Point（CP，也称"捕捉点"）是衡量机器人能否在有限步数内恢复平衡的关键概念：

$$ CP = x_{CoM} + \frac{\dot{x}_{CoM}}{\omega_0} $$

其中 $\omega_0 = \sqrt{g / z_c}$ 是LIPM的固有频率。

当CP位于支撑多边形内时，机器人可以通过调整质心位置恢复平衡（不需要迈步）。当CP超出支撑多边形时，必须迈出一步才能恢复平衡。捕捉步（Capture Step）就是落在CP位置的那一步。

8.4.2 推后反应策略​

当机器人受到外部推力时，可以采用三种策略组合：

  1. 踝关节策略：通过踝关节力矩调整质心位置——适用于小扰动
  2. 髋关节策略：通过躯干和髋关节的弯曲调整——适用于中等扰动
  3. 迈步策略：跨出一步——适用于大扰动

8.5 强化学习在行走中的应用​

近年来，基于强化学习的行走控制取得了显著进展。与传统的基于模型的方法（MPC）相比，RL方法具有以下优势：

  • 无需精确模型：直接通过试错学习策略
  • 适应性更强：可以处理传统方法难以建模的复杂地面条件
  • 奖励函数设计：通过奖励工程即可引导（而非编程）所需行为

典型方法：在MuJoCo中用PPO算法训练，配合域随机化增强鲁棒性。

🛠️ 仿真实操：PPO站立策略训练​

🕐 预计时长：60-120分钟 · 📁 代码位置：code/ch08-standing-rl/standing_ppo.py

实验目标​

使用PPO（Proximal Policy Optimization）算法在MuJoCo中训练一个抗扰动站立策略。

实验步骤​

  1. 安装并导入Stable-Baselines3
  2. 使用MuJoCo的HumanoidStandup环境（或自定义环境）
  3. 配置PPO超参数
  4. 训练智能体（约50万步）
  5. 测试训练后的策略在外部扰动下的表现

延伸思考​

  1. 尝试修改奖励函数，观察对训练行为的影响
  2. PPO的clip范围（$\epsilon$）对训练稳定性有什么影响？
  3. 训练好的策略能否泛化到不同的地面条件（摩擦系数变化）？

本章小结​

  • 双足行走的本质是一个倒立摆稳定问题，极具挑战性
  • ZMP稳定性判据是行走控制的理论基础
  • 线性倒立摆模型（LIPM）是步态规划的标准简化工具
  • Capture Point理论提供了平衡恢复的定量框架
  • 强化学习（如PPO）在行走控制中展现出巨大潜力

  1. 选择题：ZMP位于支撑多边形内意味着？ A. 机器人正在加速 B. 机器人是稳定的 C. 机器人正在迈步 D. 机器人即将摔倒

  2. 简答题：线性倒立摆模型做了哪两个关键简化？为什么这些简化使问题更容易处理？

  3. 简答题：Capture Point超出支撑多边形时，机器人必须做什么来恢复平衡？

  4. 计算题：LIPM的 $z_c = 0.8m$，质心水平速度 $\dot{x} = 0$，求固有频率 $\omega_0$。若ZMP位于 $p_x = 0.1m$，质心位于 $x = 0.05m$，求质心的加速度 $\ddot{x}$。

  5. 开放题：为什么在行走控制中RL方法近年来比传统MPC方法更受关注？两种方法各有什么优劣？
