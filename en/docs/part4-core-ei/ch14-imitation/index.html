第14章：模仿学习

本章导语：强化学习需要数百万次试错，而人类可以通过观察几次示范就学会新技能。模仿学习（Imitation Learning）试图让机器人拥有类似的能力——通过观察和模仿人类示教来学习。本章从行为克隆到扩散策略，覆盖模仿学习的核心技术。

14.1 行为克隆​

14.1.1 基本原理​

行为克隆（Behavioral Cloning, BC）是最直接的模仿学习方法。它将模仿学习转化为监督学习问题：

给定专家轨迹数据集 $\mathcal{D} = &#123;(s_i, a_i^*)&#125;{i=1}^N$，学习一个策略 $\pi\theta(a \mid s)$ 最小化：

$$ \mathcal{L}(\theta) = \mathbb{E}{(s, a^*) \sim \mathcal{D}} \left[ -\log \pi\theta(a^* \mid s) \right] $$

其中 $s$ 是状态，$a^*$ 是专家在状态 $s$ 下执行的动作。

14.1.2 分布偏移问题（Covariate Shift）​

行为克隆有一个致命缺陷：分布偏移（Covariate Shift）。训练数据是从专家轨迹分布中采样的，但部署时策略会遇到不在训练分布中的状态——微小的误差会随着时间累积，导致策略"偏离轨道"。

训练时的状态分布：s ~ d_专家(s)
部署时的状态分布：s ~ d_策略(s)  ← 与训练分布不同！

这一问题的严重性随任务长度指数级增长。

14.1.3 解决方案​

DAgger（Dataset Aggregation） 是解决分布偏移的主要方法：

  1. 用初始数据集训练策略
  2. 用策略在环境中 rollout，收集新状态
  3. 让专家标注这些新状态的动作
  4. 将新数据加入数据集，重新训练
  5. 重复上述过程

14.2 扩散策略​

14.2.1 为什么需要扩散模型​

机器人动作生成有两个固有特性：

  1. 多模态：一个状态可能有多种可行的动作（如从不同角度抓取杯子）
  2. 时序平滑：动作序列需要连续平滑

传统方法（如BC的均方误差）会"平均"多个可行动作，产生模糊的中间动作。扩散模型天然适合解决这个问题。

14.2.2 扩散策略的工作原理​

扩散策略（Diffusion Policy, Chi et al. 2023）将机器人动作生成建模为去噪扩散过程：

训练阶段：从动作 $a_0$ 开始，逐步添加噪声直到变成纯高斯噪声 $a_K \sim \mathcal{N}(0, I)$，学习逆过程（去噪）。

推理阶段：从纯噪声 $a_K$ 开始，逐步去噪得到动作 $a_0$。

$$ a_{k-1} = \alpha \left( a_k - \gamma \epsilon_\theta(s, a_k, k) \right) + \mathcal{N}(0, \sigma^2 I) $$

其中 $\epsilon_\theta$ 是学习的噪声预测网络。

14.2.3 扩散策略 vs 行为克隆​

对比行为克隆扩散策略
输出分布单峰高斯多模态（任意分布）
多模态动作❌ 平均现象✅ 自然支持
时序平滑需额外处理✅ 输出动作序列
推理速度快慢（需多步去噪）
训练稳定性容易需要调参

14.3 逆强化学习​

逆强化学习（Inverse Reinforcement Learning, IRL）不直接模仿动作，而是推断专家的奖励函数，然后基于该奖励函数训练策略。

核心思想：如果专家选择了行为 $\tau_E$，那么 $\tau_E$ 的奖励期望应该高于任何其他策略的行为。

代表性的IRL方法包括：

  • 最大熵IRL（MaxEnt IRL）：在给定专家特征期望的约束下，找到熵最大的奖励函数
  • 生成式对抗模仿学习（GAIL）：用GAN的思想区分专家和策略的轨迹

🛠️ 仿真实操：行为克隆与扩散策略​

🕐 预计时长：60分钟 · 📁 代码位置：code/ch14-imitation/imitation_bc.py

实验目标​

采集仿真中的演示数据，用行为克隆和扩散策略（简化版）训练抓取策略。

实验步骤​

  1. 在 MuJoCo 中运行一个预设的"专家"轨迹（预编程运动）
  2. 记录状态-动作对作为演示数据
  3. 用行为克隆训练策略
  4. 测试行为克隆的泛化能力（观察分布偏移）
  5. （可选）实现简化版扩散策略

延伸思考​

  1. 演示数据量从10条增加到100条，BC的效果提升有多大？
  2. DAgger 能否有效缓解分布偏移？在你的实验中效果如何？
  3. 为什么扩散策略的输出比BC更平滑？

本章小结​

  • 行为克隆是最直接的模仿学习方法，但受分布偏移困扰
  • DAgger通过迭代收集新数据解决分布偏移
  • 扩散策略利用去噪生成多模态、平滑的动作序列
  • 逆强化学习通过推断专家奖励函数学习策略

习题​

  1. 选择题：行为克隆的"分布偏移"问题是指？ A. 训练数据不够多 B. 策略在未见过的状态下表现差 C. 奖励函数设计困难 D. 环境是非稳态的

  2. 简答题：扩散策略相比行为克隆的核心优势是什么？

  3. 简答题：DAgger 如何缓解分布偏移问题？

  4. 开放题：如果你要教机器人"倒水"，你会选择BC、扩散策略还是IRL？为什么？
