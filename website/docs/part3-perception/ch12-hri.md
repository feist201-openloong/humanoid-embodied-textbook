# 第12章：人机交互基础

> **本章导语**：人形机器人的最终价值在于与人互动。本章讲解人机交互的关键技术——语音交互、手势识别、意图理解和情感计算，并搭建一个完整的"语音指令→动作执行"流水线。

---

## 12.1 语音交互

### 12.1.1 语音识别（ASR）

语音识别（Automatic Speech Recognition, ASR）将人的语音转换为文字。主要方案：

| 方案 | 特点 | 适用场景 |
|:----|:-----|:---------|
| **Whisper** (OpenAI) | 离线、多语言、高精度 | 通用场景 |
| **Wav2Vec 2.0** (Meta) | 自监督训练，少量数据微调 | 定制场景 |
| **DeepSpeech** (Mozilla) | 端到端深度学习 | 开发验证 |
| 云端API（百度/阿里） | 联网、延迟低 | 快速部署 |

```python
# Whisper 语音识别
import whisper
model = whisper.load_model("base")
result = model.transcribe("audio.wav")
print(result["text"])  # "去厨房拿一杯水"
```

### 12.1.2 语音合成（TTS）

语音合成（Text-to-Speech, TTS）将文字转换为语音。推荐方案：

| 方案 | 质量 | 实时性 | 特点 |
|:----|:----:|:------:|:-----|
| **XTTS** (Coqui) | 高 | 中 | 支持多语言、声音克隆 |
| **Edge TTS** (MS) | 高 | 高 | 免费、中文效果优秀 |
| **CosyVoice** (阿里) | 高 | 高 | 中文情感合成 |

### 12.1.3 对话管理

将ASR和TTS连接起来的对话管理组件，通常由一个LLM驱动：

```
用户语音 → ASR → 文字 → LLM（理解+规划） → 响应文字 → TTS → 语音回复
                                               ↓
                                        机器人动作指令
```

## 12.2 手势识别

### 12.2.1 基于视觉的手势识别

使用RGB-D相机检测人体的手部关键点，识别手势的含义：

- **MediaPipe Hands**：Google开动手部关键点检测（21点），实时、轻量
- **手势分类**：将关键点坐标输入分类器（如SVM或MLP）识别具体手势

| 手势 | 含义 | 机器人响应 |
|:----|:-----|:----------|
| 挥手 | 打招呼 | 挥手回应 |
| 指向 | 指示方向 | 看向/走向目标 |
| 掌心向前 | 停止 | 停止运动 |
| 招手 | 过来 | 走向用户 |

### 12.2.2 基于触觉的交互

当人类触碰机器人时，力/力矩传感器可以检测接触的位置和力度。结合视觉，可以实现：
- 人类引导机器人（"跟我来"——拉着机械臂）
- 人类示范操作（"这样做"——引导机器人模拟轨迹）

## 12.3 意图理解

### 12.3.1 LLM驱动的情境理解

大语言模型为人机交互带来了革命性的提升。LLM不仅理解字面含义，还能结合上下文推断用户的真实意图：

**示例对话**：

> 用户：*"好冷。"*
> 
> 解读1（字面）：用户陈述了一个事实。
> 
> 解读2（意图）：用户希望关闭空调或关窗。

LLM可以结合场景（机器人能做什么、环境有哪些设备）做出合理的意图推断。

### 12.3.2 多轮对话

多轮对话（Multi-turn Dialogue）使机器人能够维持上下文：

> 用户：*"去厨房。"*
> 机器人：*（走到厨房）"到了。要我做什么？"*
> 用户：*"桌上那杯水。"*
> 机器人：*（识别水杯）"这个吗？"*
> 用户：*"对，拿过来。"*

## 12.4 情感计算

### 12.4.1 情感识别

通过视觉（面部表情）、语音（语调、语速）和生理信号推断用户的情感状态：

- **视觉情感分析**：FER2013 / AffectNet 数据集训练的面部表情识别
- **语音情感分析**：语速、音调、音量等声学特征

### 12.4.2 情感表达

人形机器人可以通过以下方式表达情感：
- **面部表情**：LED眼神、眉毛动作
- **语音音调**：改变TTS的语气和语调
- **肢体语言**：点头、歪头、手势

## 🛠️ 仿真实操：语音→动作流水线

> 🕐 预计时长：60分钟 · 📁 代码位置：`code/ch12-voice-action/voice_pipeline.py`

### 实验目标
搭建"语音识别→LLM意图解析→MuJoCo动作执行"的简单流水线。

### 实验步骤
1. 录制一段语音指令（如"抬起右手"或"前进一步"）
2. 使用 Whisper 将语音转为文字
3. 调用 LLM API（或简单规则）解析意图
4. 根据意图在 MuJoCo 中执行对应的动作

### 拓展：文本模式
如果没有麦克风，也可以直接输入文字指令：
```bash
python voice_pipeline.py --text "抬起右手"
```

## 本章小结

- 语音交互（ASR + TTS + LLM）是人机交互最自然的方式
- MediaPipe 等工具实现了实时手势识别
- LLM 驱动的意图理解使机器人能处理复杂的自然语言指令
- 情感计算让人机互动更加自然和信任
