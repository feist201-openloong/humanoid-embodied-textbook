# 第19章：综合项目Ⅰ——移动操作

> **本章导语**：综合前18章的所有知识，完成一个端到端的移动操作任务——"去拿那杯水"。机器人需要从起点出发，导航到桌子前，识别水杯，抓取并返回。这是人形机器人最典型的实用场景。

---

## 19.1 项目概要

### 19.1.1 任务描述

**输入**：自然语言指令"去厨房把桌上的那杯水拿过来"

**输出**：机器人执行完整的移动操作序列

**环境**：室内环境，包含房间、餐桌、水杯等物体

### 19.1.2 任务分解

```
指令 → 任务规划（LLM解析）
         ↓
[子任务] 导航到厨房（SLAM + 路径规划）
         ↓
[子任务] 定位桌子（视觉识别）
         ↓
[子任务] 走到桌前（步态规划 + 避障）
         ↓
[子任务] 伸手到水杯位置（逆运动学IK）
         ↓
[子任务] 抓取水杯（力控 + 灵巧手）
         ↓
[子任务] 返回起点（路径规划 + 行走）
         ↓
任务完成 ✓
```

## 19.2 系统架构

### 19.2.1 组件划分

```
┌─────────────────────────────────────────────────────┐
│                   任务规划器 (LLM)                    │
│  将自然语言指令分解为可执行的子任务序列                │
└────────────────────┬────────────────────────────────┘
                     │
    ┌────────────────┼────────────────┐
    ▼                ▼                ▼
┌──────────┐   ┌──────────┐    ┌──────────┐
│  导航模块  │   │  感知模块  │    │  操作模块  │
│  SLAM     │   │  物体检测  │    │  IK求解    │
│  路径规划  │   │  场景分类  │    │  抓取规划  │
│  避障     │   │  深度估计  │    │  力控     │
└──────────┘   └──────────┘    └──────────┘
```

### 19.2.2 数据流

```
导航 → 感知 → 到达目标位置
               ↓
          感知 → 目标定位
               ↓
          操作（IK + 力控）→ 抓取
               ↓
          导航 → 返回
```

## 19.3 关键技术

### 19.3.1 导航栈

基于ROS2 Navigation Stack（Nav2）的导航流程：

1. **全局定位**：AMCL（自适应蒙特卡洛定位）
2. **全局路径规划**：A* 或 Dijkstra
3. **局部路径规划**：DWA（动态窗口法）或 TEB（时间弹性带）
4. **代价地图**：从感知数据生成的障碍物概率地图

### 19.3.2 物体检测与定位

使用YOLO或SAM检测目标物体，结合深度图计算3D位置：

```python
# 目标检测流水线
rgb_image, depth_image = get_camera_data()
detections = yolo_model(rgb_image)        # 2D检测
for obj in detections:
    if obj.class_name == 'cup':
        cx, cy = obj.center              # 图像中心
        Z = depth_image[cy, cx]          # 深度
        X = (cx - cx0) * Z / fx         # 反投影
        Y = (cy - cy0) * Z / fy
        target_pos = [X, Y, Z]            # 相机坐标系中的位置
```

### 19.3.3 抓取规划

抓取规划需要确定：
- **抓取姿态**：手接近物体的方向（垂直/水平/倾斜）
- **抓取力**：根据物体材质和质量确定
- **避碰轨迹**：手在移动过程中不与障碍物碰撞

## 19.4 状态机

任务执行使用状态机驱动：

```
IDLE → NAVIGATING → APPROACHING → REACHING → GRASPING → RETRIEVING → DONE
```

每个状态转换由感知结果触发：
- `NAVIGATING → APPROACHING`：到达桌前
- `APPROACHING → REACHING`：手臂就绪
- `REACHING → GRASPING`：手在目标位置
- `GRASPING → RETRIEVING`：抓取成功
